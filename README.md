# MyKanBan

This will be the basis of a KanBan system where users can create cards and move them through each stage of completion

### Why this?

I am making this to be an easily manipulated way of task management, that is simple to use and manipulate and can help to become a core part of my own / others workflow. This is to replace my current system of coloured sticky notes, of which don't withstand multiple movements over multiple days due to the adhesive. This is to help replace that.

### Features that will be implemented before release

-Creation of Cards (obviously)
-Storage of Card Data locally
-Movement of Cards between stages (drag and drop)
-Urgency coding into Cards
-Editing / Deletion of Cards prior to expiry

### Features expected in future

-Additional parameters that can be set when creating a card (eg. estimated time, difficulty? etc for optimisation of sequencing)
-Google Calendar Compatability
-Self-Hosted remote option that can be edited viewed from multiple devices, likely through tailscale or other VPN/Proxy



This project will end up being "open source", or at least under a license that allows free access for personal use but restricts commercialisation.
